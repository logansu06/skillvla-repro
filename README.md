# SkillVLA 仿真机制级复现

复现 [SkillVLA (arXiv:2603.03836)](https://arxiv.org/abs/2603.03836) 的核心论点：双臂 VLA 把左右臂动作拼在一起生成，会造成技能纠缠，没见过的左右技能组合会失败；分臂推理加门控跨臂通信能解决这个问题，同时保留协作能力。

这是在自建简化仿真里、用从头训练的小模型做的**机制级**复现。基线是模仿 π0.5 / TwinVLA 结构的小模型，不是真实的 π0.5 或 TwinVLA；高层 VLM 用规则代替。只比较方法之间的趋势，数值不能和论文直接对比。

| 结果（3 个种子，每格 50 回合） | Mono（π0.5-like） | TwinVLA-like | SkillVLA | 论文 SkillVLA |
|---|---|---|---|---|
| 未见左右组合（零样本） | 0.00 | 0.00 | **0.46** | 0.51 |
| 协作任务平均 | 0.60 | 0.66 | **0.70**（去掉跨臂注意力后 0.18） | 0.48（去掉后 0.17） |
